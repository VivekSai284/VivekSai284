#### 2. Shop Inventory Ledger

A full-stack inventory management application designed for small businesses to track products and stock movements.

- Product and SKU management.

- Role-based access control.

**Tech:** MongoDB, Express.js, React, Node.js.

**Tech:** Python, AI/ML, Computer Vision, React Native, Expo.
